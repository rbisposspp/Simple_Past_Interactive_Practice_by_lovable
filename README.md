# Simple Past Interactive Practice

## What it is
Simple Past Interactive Practice is a lightweight ESL grammar app focused on simple past sentence formation and controlled learner feedback. The whole activity runs from a single HTML file with embedded styles and scripts.

## Who it is for
This project is intended for ESL teachers, adult learners, and live 1-on-1 lessons where quick access matters. It works well for review classes, homework follow-up, or short grammar practice blocks during online teaching.

## Main features
- Single-file browser app with no build step
- Multiple activity formats, including quiz, cloze, and guided correction
- Immediate feedback and progress tracking
- Final summary view for session wrap-up
- Responsive layout for desktop and mobile use
- Lightweight structure that is easy to reuse in class

## Teaching value
The app supports focused grammar review without extra setup. It allows teachers to move learners through several short tasks in one place and keep attention on sentence formation, accuracy, and controlled practice.

## Tech stack
- HTML
- CSS
- Vanilla JavaScript

## How to run
Open `Simple_Past_Interactive_Practice_by_lovable.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/Simple_Past_Interactive_Practice_by_lovable.html`.

## Notes
The project is intentionally compact and centered on a single grammar topic. No build tooling is required.
